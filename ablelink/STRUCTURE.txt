🚀 INSTALLATION & DEMARRAGE
═══════════════════════════════════════════════════════════════════════════════

1️⃣  LANCER XAMPP
    • Ouvrir XAMPP Control Panel
    • Démarrer Apache
    • Démarrer MySQL

2️⃣  CREER LA BASE DE DONNEES
    • Ouvrir http://localhost/phpmyadmin
    • Créer une nouvelle base: "ablelink_db"
    • Importer le fichier db/setup.sql
    • Vérifier les tables: success_stories, comments

3️⃣  ACCEDER A L'APPLICATION
    • Page de bienvenue: http://localhost/projetweb/ablelink/welcome.html
    • Accueil: http://localhost/projetweb/ablelink/index.html
    • Success Stories: http://localhost/projetweb/ablelink/success-stories.html
    • Tableau de bord: http://localhost/projetweb/ablelink/dashboard.html
    • Vérifier install: http://localhost/projetweb/ablelink/install.php

4️⃣  TESTER LES FONCTIONNALITES
    • Créer une success story
    • Ajouter des commentaires
    • Liker les histoires et commentaires
    • Modifier et supprimer

📊 BASE DE DONNEES
═══════════════════════════════════════════════════════════════════════════════

TABLE: success_stories
┌─────────────────────────────────────────────────────────────────────────────┐
│ id INT(11) AUTO_INCREMENT PRIMARY KEY                                       │
│ title VARCHAR(255) NOT NULL                                                 │
│ author VARCHAR(255) NOT NULL                                                │
│ category VARCHAR(100) NOT NULL                                              │
│ description TEXT NOT NULL                                                   │
│ image VARCHAR(255)                                                          │
│ likes INT DEFAULT 0                                                         │
│ created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP                              │
│ updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP  │
└─────────────────────────────────────────────────────────────────────────────┘

TABLE: comments
┌─────────────────────────────────────────────────────────────────────────────┐
│ id INT(11) AUTO_INCREMENT PRIMARY KEY                                       │
│ story_id INT NOT NULL (Foreign Key → success_stories.id)                    │
│ author VARCHAR(255) NOT NULL                                                │
│ comment_text TEXT NOT NULL                                                  │
│ likes INT DEFAULT 0                                                         │
│ created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP                              │
└─────────────────────────────────────────────────────────────────────────────┘

🔗 API REST ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

SUCCESS STORIES
├── GET    /api/success_stories.php              → Récupérer toutes les histoires
├── GET    /api/success_stories.php/{id}        → Récupérer une histoire
├── POST   /api/success_stories.php              → Créer une histoire
├── PUT    /api/success_stories.php/{id}        → Modifier une histoire
├── DELETE /api/success_stories.php/{id}        → Supprimer une histoire
└── POST   /api/success_stories.php/{id}/like   → Aimer une histoire

COMMENTAIRES
├── GET    /api/comments.php?story_id={id}      → Récupérer les commentaires
├── POST   /api/comments.php                    → Créer un commentaire
├── DELETE /api/comments.php/{id}               → Supprimer un commentaire
└── POST   /api/comments.php/{id}/like          → Aimer un commentaire

7. Protection XSS

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Erreur: "Connexion à la base de données refusée"
→ Vérifier que MySQL est lancé
→ Vérifier les identifiants dans db/database.php
→ Vérifier que la base "ablelink_db" existe

Erreur: "404 Not Found"
→ Vérifier l'URL: http://localhost/projetweb/ablelink/
→ Vérifier que Apache est lancé
→ Vérifier la structure des dossiers

Erreur: "Les stories ne s'affichent pas"
→ Ouvrir la console (F12) pour voir les erreurs
→ Vérifier que api/success_stories.php retourne du JSON
→ Vérifier que la base de données a des données

CSS/JS ne se charge pas:
→ Vérifier les chemins relatifs dans les fichiers HTML
→ Vérifier que les fichiers existent
→ Vérifier les permissions des fichiers
