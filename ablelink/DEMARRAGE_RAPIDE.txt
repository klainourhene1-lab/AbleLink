📊 BASE DE DONNEES
═══════════════════════════════════════════════════════════════════════════════

2 TABLES PRINCIPALES:

TABLE: success_stories (Histoires de Succès)
├─ id (Integer, Primary Key, Auto Increment)
├─ title (String)
├─ author (String)
├─ category (String)
├─ description (Text)
├─ image (String - URL)
├─ likes (Integer, Default: 0)
├─ created_at (Timestamp - Auto)
└─ updated_at (Timestamp - Auto)

TABLE: comments (Commentaires)
├─ id (Integer, Primary Key, Auto Increment)
├─ story_id (Integer, Foreign Key → success_stories)
├─ author (String)
├─ comment_text (Text)
├─ likes (Integer, Default: 0)
└─ created_at (Timestamp - Auto)

RELATION: Cascade delete (supprimer une story = supprimer ses commentaires)

🔗 API REST ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

SUCCESS STORIES:
├─ GET    /api/success_stories.php           → Récupérer toutes
├─ GET    /api/success_stories.php/1        → Récupérer une (#1)
├─ POST   /api/success_stories.php           → Créer (JSON body)
├─ PUT    /api/success_stories.php/1        → Modifier (JSON body)
├─ DELETE /api/success_stories.php/1        → Supprimer
└─ POST   /api/success_stories.php/1/like   → Aimer

COMMENTAIRES:
├─ GET    /api/comments.php?story_id=1      → Récupérer de la story #1
├─ POST   /api/comments.php                 → Créer (JSON body)
├─ DELETE /api/comments.php/1               → Supprimer le commentaire #1
└─ POST   /api/comments.php/1/like          → Aimer le commentaire

🚨 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ "Erreur de connexion à la BD"
   → Vérifier que MySQL est démarré
   → Vérifier les identifiants (user: root, pwd: vide)
   → Vérifier que la base existe

❌ "404 Not Found"
   → Vérifier l'URL
   → Vérifier que Apache est démarré
   → Vérifier la structure des dossiers

❌ "Les données ne s'affichent pas"
   → Ouvrir F12 (Console) pour voir les erreurs
   → Vérifier le statut HTTP 200
   → Vérifier que la requête API retourne du JSON

❌ "CSS/JS ne charge pas"
   → Vérifier les chemins relatifs
   → Vérifier que les fichiers existent
   → Regarder le Network tab en F12

❌ "Modal ne s'ouvre pas"
   → Vérifier la console
   → Vérifier que app.js est chargé
   → Vérifier les IDs du HTML
