TABLE 1: success_stories (Histoires de Succès)
┌──────────────────────────────────────────────────────────────────────────┐
│ Champs:                                                                  │
│  • id (Integer, Primary Key, Auto Increment)                           │
│  • title (String 255) - Titre de l'histoire                            │
│  • author (String 255) - Nom de l'auteur                               │
│  • category (String 100) - Catégorie (Career, Tech, Business, etc)    │
│  • description (Text) - Contenu de l'histoire                          │
│  • image (String URL) - Image associée                                 │
│  • likes (Integer, Default: 0) - Compteur de likes                    │
│  • created_at (Timestamp Auto) - Date de création                      │
│  • updated_at (Timestamp Auto) - Date de modification                  │
└──────────────────────────────────────────────────────────────────────────┘

TABLE 2: comments (Commentaires)
┌──────────────────────────────────────────────────────────────────────────┐
│ Champs:                                                                  │
│  • id (Integer, Primary Key, Auto Increment)                           │
│  • story_id (Integer, Foreign Key) - Référence à l'histoire            │
│  • author (String 255) - Nom du commentateur                           │
│  • comment_text (Text) - Contenu du commentaire                        │
│  • likes (Integer, Default: 0) - Compteur de likes                    │
│  • created_at (Timestamp Auto) - Date de création                      │
│                                                                          │
│ RELATION: Cascade delete                                                │
│ (Supprimer une story supprime automatiquement ses commentaires)        │
└──────────────────────────────────────────────────────────────────────────┘

   ✓ Vérifier que Apache est démarré

❌ "Les données ne s'affichent pas"

   ✓ Vérifier les erreurs JavaScript
