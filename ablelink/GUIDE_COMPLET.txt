📋 ÉTAPES POUR FAIRE FONCTIONNER:

ÉTAPE 1: Exécuter le SQL
─────────────────────────
1. Ouvrir http://localhost/phpmyadmin
2. Sélectionner la base "ablelink_db" (à gauche)
3. Cliquer sur l'onglet "SQL" (en haut)
4. Copier et coller ce code:

   ALTER TABLE success_stories ADD COLUMN status VARCHAR(20) DEFAULT 'pending' AFTER likes;

5. Cliquer "Exécuter"
6. Message: "La requête s'est exécutée avec succès"

ÉTAPE 2: Tester le flux complet
────────────────────────────────
1. Aller sur: http://localhost/projetweb/ablelink/index_simple.php
2. Cliquer sur "Histoires" dans le menu
3. Cliquer sur "✍️ Partager Votre Histoire"
4. Remplir le formulaire:
   - Titre: Ex: "Mon premier emploi"
   - Auteur: Votre nom
   - Catégorie: Sélectionner
   - Description: Raconter l'histoire (min 50 caractères)
   - Image: URL optionnel
5. Cliquer "📤 Soumettre l'histoire"
6. Message: "Histoire crée avec succès!" 
   (elle est maintenant en attente)

ÉTAPE 3: Valider l'histoire en admin
─────────────────────────────────────
1. Cliquer sur "🔐 Admin" dans le menu
2. Identifier-vous:
   - Utilisateur: admin
   - Mot de passe: admin123
3. Cliquer "Connexion"
4. Voir votre histoire en attente ⏳
5. Cliquer "✅ Approuver"
6. Message: "Histoire approuvée!"

ÉTAPE 4: Voir l'histoire publiée
─────────────────────────────────
1. Cliquer sur "Histoires" 
2. Votre histoire s'affiche maintenant! ✨
3. Cliquer dessus pour voir les détails
4. Laisser un commentaire 💬
5. Faire un like ❤️

ÉTAPE 5: Voir l'historique complet
───────────────────────────────────
1. Cliquer sur "📜 Historique"
2. Voir TOUTES les histoires avec leurs statuts
3. Voir les statistiques globales
